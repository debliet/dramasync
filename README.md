# 🎬 DramaSync

**Track your stories. Share your thoughts. Avoid spoilers.**

DramaSync is a web application prototype designed to help users organize and track TV shows, dramas, and movies while sharing their watching experiences with friends, without unwanted spoilers.

The project is being developed as an individual undergraduate Computer Science capstone project (TCC).

## 📖 About the Project

Keeping track of multiple TV shows and remembering which episode you last watched can be challenging, especially when watching alongside friends who follow different schedules.

DramaSync aims to make this experience more organized, interactive, and spoiler-friendly.

Its main feature is a spoiler control system designed to respect each user's watching progress, allowing friends to share comments and experiences without accidentally revealing events from episodes others haven't watched yet.

## ✨ Planned Features

- **Personal Library:** Organize titles into Watching, Plan to Watch, and Completed lists.
- **Episode Tracking:** Keep track of watching progress by season and episode.
- **Comments and Notes:** Write comments for individual episodes and final thoughts about completed seasons.
- **Friends:** Connect with other users and share watching experiences.
- **Spoiler Control:** Restrict access to episode-related comments based on each user's progress.
- **Search:** Find TV shows and movies to add to a personal library.
- **Profile and Notifications:** Manage personal information and view social interactions.

## 🎞️ TMDB API Integration

DramaSync plans to integrate the TMDB API to retrieve movie and TV show information, including titles, descriptions, posters, seasons, and episodes.

This integration will support the application's search and library features.

The API will be used exclusively for educational, non-commercial purposes.

DramaSync is not a streaming platform and does not provide or distribute video content.

## 🚧 Project Status

**Currently under development.**

DramaSync is an academic front-end prototype. Its interface and navigation are being developed and refined, while additional functionality and external API integration are planned for future development stages.

## 📚 Academic Purpose

This project is part of the final undergraduate requirements for a Computer Science degree.

Its objective is to explore front-end web development, user interaction, application structure, and the implementation of a spoiler-aware content tracking experience.
